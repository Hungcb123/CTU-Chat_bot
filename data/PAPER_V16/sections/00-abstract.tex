\begin{abstract}
University counseling spans relational curricula, cohort-specific fees, exemption policies, and narrative regulations, each requiring distinct evidence representations. Whether decomposing this heterogeneous task into specialized agents improves reliability over an equivalent single agent remains underexplored. We present CTU-Chat, a supervisor-routed multi-agent system assigning queries to four bounded specialists with scoped tools and representation-specific evidence paths: Neo4j graph traversal for curricula, structured lookup with deterministic calculation for financial data, and hybrid retrieval with neural reranking for regulations. Scenarios~1 and 2 use a 100-query held-out benchmark for architecture comparison and ablation, respectively. The former compares CTU-Chat with a matched single-agent baseline and a routed generic variant; the latter removes specialist policies, tool isolation, heterogeneous evidence, deterministic calculation, and route repair. Scenario~3 uses 50 separate cases to stress-test tool ambiguity across 11, 31, and 51 tools. In architecture comparison, CTU-Chat achieves a 10.0\,pp higher Automated Fact Pass Rate ($\text{Pass}_{\ge 50\%}$) point estimate (76.0\% vs.\ 66.0\%; paired 95\% CI $[+2.0, +19.0]$\,pp; exact McNemar $p{=}0.0414$) with 41.4\% fewer recorded specialist input tokens, alongside an unlogged upstream routing overhead of ${\sim}650$ tokens and sequential dispatch latency (10.65\,s pipeline vs.\ 5.16\,s post-retrieval baseline). Under registry expansion to 51 tools, the scoped specialist achieves 88.0\% tool E2E Success (vs.\ 78.7\% for Top-10 selection). These findings suggest that domain-scoped specialization and heterogeneous evidence allocation may improve fact-pass performance under the evaluated conditions, with measurable trade-offs in coordination latency and token consumption.

\end{abstract}
