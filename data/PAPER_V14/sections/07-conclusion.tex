\section{Conclusion and Future Work}
\label{sec:conclusion}

This study evaluated \system{}, a supervisor-routed multi-agent RAG framework for university counseling, across architecture comparison, ablation, and tool ambiguity stress testing.
Three principal findings address the research questions: (1)~CTU-Chat achieves a 10.0\,pp higher Automated Fact Pass Rate ($\text{Pass}_{\ge 50\%}$) point estimate than a matched single-agent baseline (76.0\% vs.\ 66.0\%; paired CI $[+2.0, +19.0]$\,pp; exact McNemar $p{=}0.0414$) with 41.4\% fewer recorded specialist input tokens (and ${\sim}650$ routing tokens per query); (2)~removing specialist policies corresponds to a $-10.0$\,pp pass rate drop, while replacing heterogeneous evidence allocation reduces Source Recall by $-12.3$\,pp; and (3)~the Routed Specialist sustains 88.0\% tool E2E Success at 51 tools, compared with 83.3\% for the Full-Registry Single Agent and 78.7\% for Global Top-10.
Supervisor-routed specialization supports heterogeneous institutional counseling: domain policies, representation-specific evidence paths, and deterministic calculations contribute to reliability, while scoped tool access provides a scalability safeguard under registry expansion, trading off against sequential dispatch latency.
Future work includes reducing dispatch latency via speculative routing, evaluating multi-institutional transfer across bilingual curricula, and conducting live longitudinal counseling trials.
