\subsection{Architectural Findings and Operational Trade-offs}

\textbf{RQ1 (Architecture-Level Effectiveness):}
The architecture-level comparison indicates that supervisor-routed multi-agent decomposition achieves a 10.0\,pp higher Automated Fact Pass Rate ($\text{Pass}_{\ge 50\%}$) point estimate than the Unified Single Agent (76.0\% vs.\ 66.0\%; paired bootstrap CI $[+2.0, +19.0]$\,pp; exact McNemar $p{=}0.0414$), alongside higher Fact Coverage (+3.58\,pp, 95\%\,CI $[-1.2, +8.5]$\,pp) and 41.4\% fewer recorded specialist input tokens (3{,}690 vs.\ 6{,}296; supervisor adds ${\sim}650$ routing tokens/query), while end-to-end dispatch latency exceeds post-retrieval generation (10{,}652 vs.\ 5{,}159\,ms). Routed Generic records lower Fact Coverage (54.2\% vs.\ 61.0\%; $\Delta{=}-6.85$\,pp, $p{<}0.05$), showing that specialist policies contribute substantially to answer fidelity under shared routing.

\textbf{RQ2 \& RQ3 (Mechanisms, Tool Isolation, and Registry Scaling):}
Component ablations reveal two distinct roles. \emph{Accuracy drivers:} Heterogeneous evidence access (S2-A3) was associated with 12.3\,pp higher Source Recall overall (and $+17.8$\,pp on structured finance); specialist policies (S2-A1) govern coverage ($-6.85$\,pp Fact Coverage); route repair (S2-A5) provides cross-domain robustness ($-15.0$\,pp); and the calculator-enabled configuration (S2-A4) achieved 8/9 numeric exact matches on tuition queries, versus 3/9 without calculators.
Conversely, \emph{scalability and efficiency mechanisms:} At 11 tools, tool isolation (S2-A2) does not alter pass rate ($\Delta\text{Pass}_{.50} = 0.0$\,pp, CI $[-6.0, +6.0]$\,pp) but adds $+1{,}270$ input tokens (+34.4\%), acting as a cost-containment safeguard rather than an accuracy driver at small scales. Under registry expansion (Scenario~3), scaling to 51 tools with semantic distractors, the Routed Specialist sustains 88.0\% tool E2E Success with 9.8 visible tools, compared with 78.7\% for Global Top-10 ($+9.3$\,pp, CI $[+2.0, +17.3]$\,pp; candidate truncation) and 83.3\% for Full-Registry Single Agent ($+4.7$\,pp, CI $[-1.3, +11.3]$\,pp) while using 52.4\% fewer input tokens (1{,}770 vs.\ 3{,}722). In the tested registries, specialization kept per-agent tool exposure bounded.

\textbf{Latency Decomposition and Operational Guidance:}
Operational trade-offs reflect distinct boundaries:
(1)~\emph{Measurement boundaries:} Single-agent timing measures inference post-retrieval ($5{,}159$\,ms), whereas multi-agent variants measure end-to-end dispatch inclusive of routing ($8{,}921$--$10{,}652$\,ms).
(2)~\emph{Contract overhead:} The $+1{,}731$\,ms delta between generic and specialist multi-agent execution is driven by structured contract generation (+48\% output tokens, $2{,}092$ vs.\ $1{,}415$), with supervisor routing adding ${\sim}650$ input tokens.
(3)~\emph{Deployment guidance:} Monolithic single-agent designs suit low-latency, single-domain queries with small tool pools (${\le}10$); supervisor-routed multi-agent architectures are justified when counseling demands heterogeneous evidence representations, deterministic arithmetic fidelity, and tool isolation under expanding registries.

\subsection{Relation to Prior Work}

While ReAct~\cite{yao2023react} and Toolformer~\cite{schick2023toolformer} integrate tools within single agents, full-registry single agents suffer severe prompt expansion as tools scale. Unlike collaborative frameworks (e.g., AutoGen~\cite{wu2023autogen}) where chatter compounds latency, \system{} enforces bounded single-owner dispatch with route repair. Ablation S2-A3 highlights text retrieval limits on relational curricula, corroborating GraphRAG's rationale for heterogeneous evidence~\cite{edge2024graphrag}. Unlike Adaptive-RAG's linguistic complexity branching~\cite{jeong2024adaptiverag}, \system{} routes queries by institutional data modality.

\subsection{Threats to Validity}
\label{sec:limitations}
\textbf{Internal:} Evaluations use Gemini 2.5 Flash Lite with greedy decoding ($\tau{=}0$); cloud API serving variations remain operational confounds. \textbf{External:} The benchmark reflects Can Tho University statutes; multi-campus transfer across bilingual or trimester curricula remains future work. Semantic neighbors in Scenario~3 are controlled synthetic constructs. \textbf{Construct:} Automated substring matching ($\text{Pass}_{\ge 50\%}$) checks lexical phrase occurrence rather than computational validity; e.g., in query \texttt{HOUT-DIR-FIN-03}, regulatory keywords matched 50\% coverage despite an incorrect tuition calculation (192.183M vs.\ 40M VND). We mitigate this by pairing lexical metrics with deterministic tool validation (Scenario~3) and bursar exact-match audits ($N{=}9$). \textbf{Statistical:} Paired bootstrap resampling uses 10,000 iterations ($N{=}100$); arithmetic exact match ($N{=}9$) has a small sub-cohort, though the 8/9 vs.\ 3/9 delta is substantial. \textbf{Operational:} Latencies reflect cloud API execution and network transport.
