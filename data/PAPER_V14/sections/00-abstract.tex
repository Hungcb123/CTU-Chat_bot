\begin{abstract}
University counseling spans relational curricula, cohort-specific fees, exemption policies, and narrative regulations, each requiring distinct evidence representations. Whether decomposing this heterogeneous task into specialized agents improves reliability over an equivalent single agent remains underexplored. We present CTU-Chat, a supervisor-routed multi-agent system assigning queries to four bounded specialists with scoped tools and representation-specific evidence paths: Neo4j graph traversal for curricula, structured lookup with deterministic calculation for financial data, and hybrid retrieval with neural reranking for regulations. We evaluate CTU-Chat across three scenarios on a 100-query held-out benchmark: (1)~architecture-level comparison against a matched single-agent baseline and a routed generic variant under identical capabilities; (2)~architectural ablations removing specialist policies, tool isolation, heterogeneous evidence, deterministic calculation, and route repair; and (3)~a semantic-neighbor tool-ambiguity stress test across 11, 31, and 51 tools. In architecture comparison, CTU-Chat achieves a 10.0\,pp higher Automated Fact Pass Rate ($\text{Pass}_{\ge 50\%}$) point estimate (76.0\% vs.\ 66.0\%; paired 95\% CI $[+2.0, +19.0]$\,pp; exact McNemar $p{=}0.0414$) with 41.4\% fewer recorded specialist input tokens, alongside an unlogged upstream routing overhead of ${\sim}650$ tokens and sequential dispatch latency (10.65\,s pipeline vs.\ 5.16\,s post-retrieval baseline). Under registry expansion to 51 tools, the scoped specialist sustains 88.0\% tool E2E Success (vs.\ 78.7\% for Top-10 selection). These findings indicate that domain-scoped specialization and heterogeneous evidence allocation support institutional counseling reliability, with measurable trade-offs in coordination latency and token footprint.

\end{abstract}
