\begin{abstract}
Higher education student counseling involves heterogeneous institutional knowledge, spanning relational curriculum graphs, cohort-specific tuition matrices, statutory exemption criteria, and narrative administrative decrees. Monolithic RAG frameworks and uncoordinated agent meshes can be brittle in this setting because of uniform representations, cross-domain evidence interference, and unconstrained tool exposure. We present \textbf{\system{}}, a centralized supervisor-routed, domain-specialized multi-agent architecture in which each specialist is assigned a domain-specific knowledge space, retrieval path, and tool privilege for Vietnamese university counseling. Under centralized supervisor coordination, \system{} dispatches user queries to four bounded specialists with asymmetric privileges across three tiers: relational academic curricula are resolved through dedicated Cypher tools over a Neo4j knowledge graph, structured tuition rates are resolved via graph lookup and JSON catalogs with deterministic arithmetic engines, and narrative administrative regulations are retrieved through a hybrid document RAG path (BM25 and dense embeddings fused via Reciprocal Rank Fusion and cross-encoder reranking). Multi-agent evaluation demonstrates 97.0\% supervisor routing accuracy (97.8\% Macro-F1) and 100.0\% bounded completion under strict invariants ($\text{max\_tool\_calls}=1$, timeout $=60.0\,\text{s}$). Across 60 production-tool cases repeated three times, academic lookup, tuition-policy, scholarship, and no-tool gates achieved 100.0\% end-to-end pass, while graph tuition lookup achieved 80.0\% and graph exemption-basis lookup 73.3\%. On the 150-question benchmark, progressive component stacking achieves $0.9000$ Hit@1, $0.9600$ Hit@3, $0.8656$ Recall@5, and $0.9327$ MRR.

\keywords{Multi-Agent Systems \and Domain-Specialized Agents \and Centralized Supervisor Routing \and Heterogeneous Knowledge Allocation \and Retrieval-Augmented Generation \and University Counseling}
\end{abstract}
